# Arquivos fornecidos para uso local

Esta pasta recebe os documentos originais do usuário e suas extrações de trabalho. O conteúdo é ignorado pelo Git para evitar publicar textos de terceiros e afirmações numéricas ainda não verificadas. Os arquivos continuam no diretório local e podem ser selecionados para importação na aplicação.

- `50_materias_para_importar.txt`: extração estruturada do DOCX, destinada à página `/historico`. Revise metadados e o limite por documento antes de enviar.
- `afirmacoes_do_pdf_para_revisao.csv`: transcrição das afirmações numeradas do PDF. Cada linha está marcada `NAO_VERIFICADA`; não carregar como série oficial sem confirmar URL, período, unidade e valor na fonte primária.

Os arquivos originais ficam preservados nesta pasta. Verifique licença e permissão de uso antes de distribuir os textos ou fazer commit deles em repositório remoto.
